Official app icons for the Tools dock
=====================================

Put each app's icon in this folder with exactly these names (SVG or PNG;
PNG at least 256x256 with a transparent background):

  figma.svg          after-effects.svg   illustrator.svg   photoshop.svg
  premiere-pro.svg   higgsfield.svg      midjourney.svg    runway.svg
  chatgpt.svg        claude.svg

Each file automatically replaces the drawn glyph inside its glass tile.
Any icon that is missing keeps the drawn glyph. Use icons from each
company's official press/brand kit and follow its usage guidelines.
